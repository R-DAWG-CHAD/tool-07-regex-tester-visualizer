# ⚡ Real-Time Regex Tester & Visual Match Engine

An interactive, browser-based Regular Expression (Regex) debugger, match highlighter, capture group inspector, and pattern replacement engine.

## 🚀 Key Features

- **Real-Time Match Highlighting:** Visually highlights all regex matches directly within the test input text container.
- **Capture Group Inspector:** Breaks down matched groups (`$1`, `$2`, etc.) in structured card displays.
- **Substitution / Replacement Engine:** Evaluates pattern substitution strings in real time.
- **JavaScript Regex Flags:** Toggle `g` (global), `i` (case insensitive), `m` (multiline), `s` (dotall), and `u` (unicode).
- **Preset Pattern Library:** Instant one-click presets for Emails, Web URLs, IPv4 Addresses, Phone Numbers, ISO Dates, and HEX Colors.
- **Performance Execution Counter:** Reports evaluation duration in milliseconds.
- **Dark Mode Glassmorphism UI:** Modern, responsive dark theme design system.
- **Zero External Dependencies:** Native HTML5, CSS3, and JavaScript.
